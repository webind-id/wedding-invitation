# Huruf untuk gambar pratinjau tautan (og:image)

File WOFF statis dari Fontsource 5.3.0 (subset latin), dipakai `src/app/[slug]/og/route.ts`
karena renderer gambar tidak bisa memakai huruf dari `next/font`.

| Berkas | Huruf | Lisensi |
| --- | --- | --- |
| `allura-latin-400-normal.woff` | Allura | SIL Open Font License 1.1 |
| `cormorant-garamond-latin-500-*.woff` | Cormorant Garamond | SIL Open Font License 1.1 |
| `manrope-latin-*-normal.woff` | Manrope | SIL Open Font License 1.1 |

OFL mengizinkan pemakaian, penyertaan, dan distribusi bersama perangkat lunak.
